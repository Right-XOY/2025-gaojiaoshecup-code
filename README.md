# 2025 高教社杯全国大学生数学建模竞赛 A 题：烟幕干扰弹的投放策略

本项目针对 **2025 年高教社杯全国大学生数学建模竞赛 A 题**，建立无人机投放烟幕干扰弹的数学模型，设计投放策略，使烟幕云团对来袭导弹所保护的真目标形成尽可能长的有效遮蔽。

- **题目原文**：[`background/A题.md`](background/A题.md)
- **建模与求解思路**：[`report/`](report/)（`q1.md` ~ `q5.md`）
- **求解代码**：[`code/`](code/)（MATLAB）

## 环境要求

- **MATLAB R2021a 或更高版本**
- 工具箱依赖：
  - `q2_main.m` 使用遗传算法 `ga` + 模式搜索 `patternsearch`（需 **Global Optimization Toolbox**）
  - `q1_main.m`、`q3_main.m`、`q4_main.m`、`q5_main.m` 使用自写算法 `q3_jade.m`，**无需额外工具箱**

## 快速开始

在 MATLAB 中 `cd` 到 `code/` 目录后，直接运行对应主程序：

```matlab
cd code

q1_main   % 问题 1：单弹对 M1 的有效遮蔽时长
q2_main   % 问题 2：单弹最优投放策略（FY1 干扰 M1）
q3_main   % 问题 3：三弹最优投放策略（FY1 干扰 M1）
q4_main   % 问题 4：三机接力最优投放策略（干扰 M1）
q5_main   % 问题 5：五机多弹位协同干扰三导弹
```

各主程序运行后会在控制台输出最优策略与遮蔽时长，并在 `data/` 目录写入对应 `result*.xlsx`。

## 各题求解概览

| 问题 | 场景 | 决策变量 | 算法 |
|---|---|---|---|
| Q1 | FY1 单弹干扰 M1（参数给定） | 无（正演） | 运动学 + 遮蔽判定 + 粗扫/二分 |
| Q2 | FY1 单弹干扰 M1 | θ、v、t_l、τ（4 维） | 文化基因算法（ga + patternsearch） |
| Q3 | FY1 三弹干扰 M1 | θ、v、t_l、τ ×3（8 维） | JADE 自适应差分进化 |
| Q4 | 三机各 1 弹接力干扰 M1 | 每机 θ、v、t_l、τ（12 维） | 三层分层优化（时序规划 → 单机 → 联合） |
| Q5 | 五机各至多 3 弹干扰三导弹 | 每机 θ/v + 各弹 t_l/τ | 五阶段分层（预扫描 → ILP 指派 → 子问题 → 联合 → 细步长） |

> 详细建模、约束条件、目标函数与求解思路见 [`report/`](report/)。

## 遮蔽判定口径

全部问题采用统一的**新遮蔽判定**（详见 [`docs/新遮蔽判定.md`](docs/新遮蔽判定.md)）：

- **引理 ①**：有效遮蔽时间区间为一段连续闭区间，遮蔽时长 $T = t_{end} - t_{start}$；
- **引理 ②**：整个圆柱被完全遮蔽 $\iff$ 上、下底面圆周均被完全遮蔽；
- **点遮蔽**：烟幕球（中心 $\mathbf{C}$、半径 $R=10\ \text{m}$）与「导弹—圆周点」线段 $MP$ 相交，即 $\mathbf{C}$ 到线段 $MP$ 的最近距离 $\le R$（垂足参数截断到 $[0,1]$，允许云团包裹导弹或目标端点）。
- **圆周采样点数**：$n = 100$（敏感性分析表明 $n \ge 100$ 时遮蔽时长已收敛）。
