## 一、问题描述与物理建模

### 1.1 场景

5 架无人机（FY1~FY5）、每机至多 3 枚烟幕干扰弹，同时干扰 3 枚来袭导弹（M1/M2/M3），要求使"**三导弹各自独立遮蔽时长之和**"（并集主指标）尽量大。

```
导弹初始位置（m）：
  M1 = (20000, 0, 2000)      到达假目标时刻 T_end ≈ 67.0 s
  M2 = (19000, 600, 2100)    T_end ≈ 63.75 s
  M3 = (18000, -600, 1900)   T_end ≈ 60.37 s
  三导弹均以 300 m/s 沿直线飞向假目标 (0,0,0)

无人机初始位置（m）：
  FY1 = (17800, 0, 1800)   FY2 = (12000, 1400, 1400)   FY3 = (6000, -3000, 700)
  FY4 = (11000, 2000, 1800) FY5 = (13000, -2000, 1300)
```

### 1.2 烟幕遮蔽判定（与问题2/3/4共用）

真目标为圆柱：`cylCenter=[0,200]`、`cylR=7`、`cylTop=10`、`cylBottom=0`，上下底面圆周各取 `nPhi=100` 个采样点。判定准则（利用凸性简化）：

- **点 P 被遮挡** ⇔ C 到线段 MP 的垂距 ≤ 烟幕半径 R=10m（垂足参数截断到 [0,1]，含端点）；
- **圆柱被完全遮蔽** ⇔ 上下底面圆周所有采样点同时被遮挡。

代码实现在 `q3_occlusion_window.m`：对每个时间步，向量化计算 `d = P-M`、`w = C-M`、垂足参数 `tp = (w·d)/(d·d)`，截断到 `[0,1]` 后判断垂距≤R。

### 1.3 单枚烟幕弹的物理过程

飞机以航向角 θ、速度 v 匀速直线飞行（高度恒定），在 `t_l` 时刻投放，引信延时 τ 后起爆：

```
投放点 P_l = uav0 + v·t_l·u_h          （u_h = [cosθ, sinθ, 0]）
起爆点 P_d = P_l + v·τ·u_h - [0,0,0.5·g·τ²]   （重力下沉）
云团中心 C(t) = P_d - [0,0,3]·(t-t_d)  t∈[t_d, t_d+20]   （云团以 3 m/s 下沉）
```

决策变量 = 每枚弹的 `[θ, v, t_l, τ]`。

### 1.4 总体数学模型（全局视角）

**索引与常量**：无人机 `j=1..5`、每机弹位 `q=1..3`、导弹 `m=1..3`；导弹以 300 m/s 沿直线飞向假目标，到达时刻 `T_end(m) = ‖M0_m‖ / v_m`。

**决策变量**（全部弹位）：

```
θ_j       —— 第 j 机航向角（x 轴正向逆时针，0~360°）
v_j       —— 第 j 机巡航速度（70~140 m/s）
t_l(j,q)  —— 第 j 机第 q 弹投放时刻
τ(j,q)    —— 第 j 机第 q 弹引信延时
```

由它们导出：投放点 `P_l = uav0_j + v_j·t_l·u_h(θ_j)`、起爆点 `P_d = P_l + v_j·τ·u_h − [0,0,½gτ²]`、起爆时刻 `t_d = t_l + τ`。

**目标函数**（并集主指标）：

```
max  T_total = Σ_{m=1..3}  T_m
T_m = ∫_0^{T_end(m)}  I_m(t) dt
I_m(t) = 1  ⇔  时刻 t 圆柱在导弹 M_m 视线内被至少一个云团完全遮蔽
        （"完全遮蔽"定义见 1.2：上下底面圆周各 24 点同时被遮挡）
```

**约束**：

```
(C1) 每架无人机全部弹位只服务同一枚导弹 m(j)，且每枚导弹至少被 1 机服务；
(C2) 起爆不晚于导弹到达假目标：t_d(j,q) ≤ T_end(m(j))；
(C3) 落地前起爆：τ(j,q) ≤ τ_max(j) = sqrt(2·h_j / g)；
(C4) 同机连投间隔：|t_l(j,q) − t_l(j,q')| ≥ 1 s（同机任意两弹位）；
(C5) 速度范围：70 ≤ v_j ≤ 140 m/s。
```

该模型目标是非光滑黑箱（`I_m(t)` 依赖 1.2 的几何判定）、决策变量高维，一体化直接求解不可行。利用物理结构——**遮蔽窗口时段主要由 θ/v 的几何位形决定，t_l/τ 几乎无法平移窗口、只影响窗口内拼接时长**——将模型分解为五层求解（见第二节）。

## 二、分层优化框架总览

```
第0层  精确预扫描（q5_prescan.py）
       对 5 机 × 3 导弹的每个组合做网格扫描，输出遮蔽潜力矩阵 pot
       与最优单弹参数表 scan_par（θ/v/t_l/τ/窗口时段）——数据驱动，不硬编码

第1层  任务指派（q5_assign.m）
       以 pot 为系数自动求解整数线性规划（ILP），
       输出 k=3 套候选指派（最优 + 2 次优）全部向下传递

第2层  子问题优化（q5_missile_fitness.m）
       对每套候选，M1/M2/M3 各自独立求解多弹接力子问题
       固定 θ/v = 预扫描最优，只优化 [t_l, τ]，目标=该导弹独立并集时长

第3层  联合精化（q5_joint_fitness.m）
       固定全部 θ/v，对所有弹位 [t_l, τ] 联合 JADE
       目标 = 三导弹各自独立遮蔽时长之和（并集主指标）

第4层  细步长精化（q5_main.m 内联）
       以最优候选为基础，dt=0.005 小种群 JADE 微调 t_l/τ
```

**层间数据流**（上一层输出 = 下一层输入）：

```
第0层 → pot(5×3) + scan_par（每组合最优 θ/v/t_l/τ/窗口时段）
第1层 → k=3 套候选指派（每套含各导弹的服务机列表；每机展开 q=1~3 弹位）
第2层 → 每导弹的独立并集时长 + 各弹位 [t_l,τ] 解（θ/v 取自 scan_par 固定）
第3层 → 三导弹遮蔽时长之和（3 套候选分别计算，取最优套）
第4层 → 最终投放策略 + result3.xlsx
```

**主程序执行流程（q5_main.m）**：

1. 读取 `pot` 与 `scan_par`（第0层数据文件）；
2. `cand = q5_assign(pot, 3)` 求 3 套候选指派；
3. 对每套候选循环：按候选展开 `servers`（各导弹服务机/弹位）与全局 `ginfo.slots` 弹位表；
4. **第2层**：对 M1/M2/M3 各自调用 `q5_build_seeds` 生成 10 组种子 → `q3_jade(q5_missile_fitness)` 独立求解，得各导弹独立并集时长与弹位 [t_l,τ] 解，并汇总每机固定的 θ/v；
5. **第3层**：把 3 个子问题解拼成全局初值 `x0_j` → `q3_jade(q5_joint_fitness)` 联合精化，得该候选的"三导弹遮蔽时长之和"；
6. 记录 3 套候选中 `total_joint` 最大的一套为 `best_info`；
7. **第4层**：对 `best_info` 换 dt=0.005 细步长再跑一次小种群 JADE（`q5_joint_fitness`）；
8. 结果解析（投放点/起爆点/各弹独立时长/各导弹并集时长）→ 写入 `result3.xlsx` → 输出收敛曲线、时间线、三维态势图。

## 三、第0层：精确物理预扫描（q5_prescan.py）

### 3.1 扫描范围与判定

对每个 (无人机, 导弹) 组合：

- 航向角 θ ∈ 0:10:350°（36 档）；
- 速度 v ∈ 70:10:140 m/s（8 档）；
- 投放时刻 t_l ∈ 0:1:55 s、引信延时 τ ∈ 0.5:1:min(12, τ_max) s（τ_max = sqrt(2h/g) 落地前上限）；
- 对每组参数，用与 Q2-Q4 完全相同的圆柱遮蔽判定（`occ_window`，上下底面各 24 点）沿导弹飞行时间轴逐点计算遮蔽布尔序列，`T = Σ occ · dt`。

取该组合下使 T 最大的参数作为**最优单弹参数**，最大 T 即**遮蔽潜力 pot(uav, m)**。输出到：

- `data/q5_prescan_pot.csv`：5×3 潜力矩阵；
- `data/q5_prescan_par.csv`：12 行最优单弹参数表（uav, m, θ, v, t_l, τ, bestT, 窗口起, 窗口止）。

### 3.2 潜力矩阵（精确值）

```
         M1     M2     M3
FY1    4.60   0.00   0.00
FY2    3.80   3.90   2.80
FY3    2.70   2.60   2.60
FY4    2.70   3.60   0.00
FY5    3.50   1.40   1.80
```

> 注：早期粗网格（v 仅 {80,110,140}）曾把 FY4-M1、FY4-M2 误判为 0；精确网格（v 每 10 m/s）修正为 FY4 对 M1/M2 均可行（θ=280° 附近），这是第1层 ILP 分配与初版不同的直接原因。

### 3.3 关键物理结论

- 每机最优单弹潜力集中在 1.4~4.6 s，不存在潜力显著占优的单机；
- **同机多弹可接力**：接力方向 = 单弹最优方向（迎向导弹），沿该方向以相邻投放间隔 1 s 分布多弹可延伸遮蔽窗口（数值验证 FY1→M1 由 4.6 s 提升至约 6.0 s）；若固定 θ/v 为单弹最优且不按 1 s 间隔错开，则同机多余弹位窗口与首弹重叠、独立贡献 ≈ 0；
- **M3 可行机少**：仅 FY2/FY3/FY5 潜力 >0，其中 FY3（θ=100°, v=120）最优 2.60 s。

## 四、第1层：任务指派（q5_assign.m，ILP 自动求解）

### 4.1 ILP 模型

```
决策变量 y(j,m) ∈ {0,1}：第 j 架无人机是否服务第 m 枚导弹
目标函数   max  Σ_j Σ_m  c_ij · y(j,m)         （c_ij 取精确预扫描 pot）
约束       Σ_m y(j,m) ≤ 1    （每机至多服务 1 枚导弹）
           Σ_j y(j,m) ≥ 1    （每枚导弹至少 1 架无人机服务）
```

系数 `c_ij` 取第0层精确扫描得到的**实际可达遮蔽时长 pot**（而非飞行时间折减的估计值），保证分配结果直接对应物理可实现的最优遮蔽时长。

### 4.2 求解方式（不硬编码）

`q5_assign(pot, k)` 枚举全部 `4^5 = 1024` 种组合（每机 4 种选择：不出动/服务M1/M2/M3），对满足"每弹至少被 1 机覆盖"的组合按 Σpot 排序，取前 k=3 套：

```
候选1  Σpot=18.20  M1←[FY1,FY5]  M2←[FY2,FY4]  M3←[FY3]   ← 最优
候选2  Σpot=18.10  M1←[FY1,FY2,FY5]  M2←[FY4]  M3←[FY3]
候选3  Σpot=17.30  M1←[FY1,FY4,FY5]  M2←[FY2]  M3←[FY3]
```

每机对其服务导弹投满 3 弹位（弹位编号 1~3），全部候选向下传递，由第2/3层统一择优。

> 该结果与初版启发式分配不同：FY4 修正可行后，M2 由 FY2+FY4 双机服务（不是 FY5），M1 由 FY1+FY5 双机服务，Σpot 从初版约 12 提升到 18.20 s。

## 五、第2层：单导弹子问题（q5_missile_fitness.m）

### 5.1 关键设计决策（最重要的工程修正）

> **⚠ 更正**：早期版本把 θ/v 固定为预扫描单弹最优（下文描述），结果同机多弹窗口重叠、无法接力。最终方案改为**每机 θ/v 纳入决策变量**（同机多弹共享），配合 1 s 投放间隔种子，且接力方向确认为**单弹最优方向（迎向导弹）**——见 [`report/q5.md`](../report/q5.md) 第 6 节。下文保留历史记录仅供参考。

初版让 JADE 同时优化 `[θ, v, t_l, τ]`（每弹位 4 维），结果**全部失效**——JADE 把预扫描最优种子扰动出稀疏遮蔽盆域。

物理预扫描结论：**遮蔽窗口时段主要由 θ/v 几何决定，t_l/τ 几乎无法平移窗口**。因此第2层改为：

- **固定每弹位 θ/v = 预扫描最优**（从 `scan_par` 表读取）；
- 决策变量仅 `[t_l1, τ1, ..., t_l_nS, τ_nS]`，共 2×弹位数 维；
- 多弹之间只需错开 `t_l` ≥ 1s，即可让不同弹位云团在不同时刻生效，形成"接力"。

### 5.2 目标函数与约束

第2层对导弹 m 的 `nS` 个弹位独立求解：

```
max  T_occ = ∫_0^{T_end(m)}  [ ∨_{s=1..nS}  occ_s(t) ]  dt
occ_s(t) = 圆柱在 t 时刻被第 s 弹云团完全遮蔽的 0/1 指示（1.2 判定）
s.t.  t_d(s) = t_l(s)+τ(s) ≤ T_end(m)          （起爆不晚于到达）
      τ(s) ≤ τ_max(servers.slots(s,1))          （落地前起爆）
      |t_l(a) − t_l(b)| ≥ 1 s,  a,b 同机弹位    （同机连投间隔）
```

代码以带罚函数的形式实现（最小化）：

```matlab
f = -T_occ + 约束惩罚        % 最小化，惩罚项 w=1e4
```

- 约束惩罚（w=1e4）：
  1. 起爆时刻 `t_d = t_l + τ ≤ T_end(m)`；否则罚 `w(t_d-T_end)²`
  2. 引信延时 `τ ≤ sqrt(2*h/g)`（落地前起爆）；否则罚 `w(τ-τ_max)²`
  3. **同机连投间隔** ≥ 1s；否则罚 `w(1-|t_l(a)-t_l(b)|)²`

### 5.3 种子生成（q5_main.m 局部函数 q5_build_seeds）

以预扫描最优 `[t_l, τ]` 为基准，生成 10 组变体（t_l 错开 0/3/6s 等 + τ 扰动）：

```matlab
offset_sets = {[0 3 6], [0 1.5 4], [0 4 7], [0 2 5], [0 2.5 6]};   % t_l 错开
tau_shifts  = {[0 0 0], [0 0.5 0.5], [0.5 0 0.5], [1 0.5 0.5], [-0.5 0 0]};  % τ 扰动
```

弹位序号超过 3 时偏移按 `mod(s-1,3)+1` **循环取模**（候选1中 M1 由 FY1+FY5 双机共 6 弹位，nS=6 > 3），保证不越界。确保至少一组种子满足同机连投间隔约束，引导 JADE 进入接力盆域。

## 六、第3层：三导弹联合精化（q5_joint_fitness.m）

目标为最大化**三导弹各自独立遮蔽时长之和**（并集主指标，即总体模型 1.4 的目标）：

```
max  T_total = Σ_{m=1..3}  T_m
T_m = ∫_0^{T_end(m)}  [ ∨_{s∈S_m}  occ_s(t) ]  dt
S_m = 第 m 枚导弹的全部已分配弹位
s.t.  同第2层三组约束（起爆≤T_end、τ≤τ_max、同机连投间隔≥1s）
```

代码实现（最小化）：

```matlab
T_total = Σ_m (第 m 枚导弹被其弹位云团遮蔽的并集时长)
f = -T_total + 约束惩罚
```

- 决策变量：全部弹位的 `[t_l, τ]`（对所有导弹的弹位统一编号，共 2×nS_all 维）；
- θ/v 全部固定（取第2层最优结果中的 θ/v）；
- 每条导弹子时间轴上独立求并集，再跨导弹累加——实现"独立遮蔽之和"；
- 约束与第2层相同（起爆≤T_end、τ≤τ_max、同机连投间隔≥1s）；
- 初始种子 = 第2层各子问题的解拼接 + 5 组小扰动变体（t_l 微移 0.4s、τ 微移 0.2s）。

> 说明：曾以"三导弹同一时刻同时遮蔽（交集）"为主指标实验，因三弹飞行时段错开、窗口几乎不可能对齐，交集物理上趋于 0（精确扫描最优点仅 2.1s 且与 ILP 最优分配冲突），故最终主指标采用**并集之和**，交集不提交。

## 七、第4层：细步长精化（q5_main.m 内联）

以第3层最优候选的 `[t_l, τ]` 为种子：

- `params.dt = 0.005`（细时间步长，提高遮蔽时长计算精度）；
- JADE：NP=15、MAXITER=120，X0 = 第3层解 + 3 组微小扰动（±0.05s / ±0.03s）；
- 边界按弹位所属导弹/无人机的物理上限构造。

## 八、JADE 算法（q3_jade.m，稳定复用）

JADE = 自适应差分进化（Zhang & Sanderson 2009）：

- **变异**：DE/current-to-pbest/1，引导向量取自当代前 p% 精英；
- **外部存档**：被淘汰个体入存档（上限 NP），差分项 r2 可从"种群∪存档"选；
- **F/CR 自适应**：F 由柯西分布生成（Lehmer 均值更新 μ_F），CR 由正态分布生成（均值更新 μ_CR）；
- **边界处理**：越界分量随机重置到 [lb, ub]；
- **二项交叉 + 贪婪选择**。

`opts.NP`、`opts.MAXITER`、`opts.p`、`opts.c`、`opts.X0`（可选初始种群）为输入参数。

## 九、结果解析与 result3.xlsx 写入

### 9.1 结果解析

对最优候选，逐弹位计算：

- 投放点/起爆点（含重力）；
- **独立贡献时长** T_ind：仅该弹云团对目标导弹的遮蔽时长（模板第 11 列独立填写）；
- 各导弹独立并集时长 T_m；
- 主指标 `T_total = Σ_m T_m`。

### 9.2 重要过滤逻辑

预扫描发现：**同机同 θ/v 下多余弹位的窗口时段与已生效弹位重叠，独立时长为 0**。写入 result3.xlsx 时仅填独立贡献 ≥ 0.1s 的弹位（其余留空）。最终有效弹位 = 每服务机第 1 弹位：


## 十一、论文可引用结论

1. **三导弹独立遮蔽之和 ≈ 18.4 s**（并集主指标，细步长验证），其中 M1 由 FY1+FY5 双弹接力（≈8.1s）、M2 由 FY2+FY4 双弹接力（≈7.6s）、M3 由 FY3 单弹（≈2.7s）；
2. **分配由 ILP 自动求解**：以精确预扫描 pot 为系数，最优分配 M1←[FY1,FY5]、M2←[FY2,FY4]、M3←[FY3]；
3. **FY4 对 M1/M2 均可行**（θ=280° 附近，精确扫描修正了粗网格误判），是 M2 接力的关键资源；
4. **M3 只能由 FY3 等少数机有效遮蔽**，且单弹潜力 ≤2.8s——M3 最早到达假目标（T_end≈60.4s 为三者最小），且几何最不利；
5. **同机多弹可沿单弹最优方向接力**——接力方向即单弹最优方向（迎向导弹），以 1 s 间隔分布多弹可延伸窗口（FY1→M1 由 4.6 s 提升至约 6.0 s）；早期「固定 θ/v」的做法才会导致多余弹位窗口重叠；
6. **三导弹同时遮蔽（交集）物理上趋近 0**，故主指标采用"独立遮蔽时长之和"。
